## 3. 竞品功能对比

| 功能 | 本项目 (v1.5) | DBHub (bytebase) | 官方 PG/SQLite MCP | Supabase MCP |
|------|--------------|-------------------|---------------------|-------------|
| **引擎数** | **6（PG/MySQL/MSSQL/Oracle/Mongo/Redis）** | 4（PG/MySQL/SQLite/MSSQL） | 1 | 1（PG） |
| **工具数** | **80** | ~15 | 2-5 | ~10 |
| **SQL 注入防护** | **16+ 模式** | 基础 | 无 | 无 |
| **数据脱敏** | **strict/loose 模式** | 无 | 无 | 无 |
| **审计日志** | **内存 1000 条 + 统计** | 无 | 无 | RLS 策略 |
| **查询建议** | **规则引擎** | 无 | 无 | 无 |
| **传输协议** | stdio | stdio + HTTP | stdio | stdio |
| **OAuth 认证** | 无 | 无 | 无 | **内置 Auth** |
| **RBAC 权限** | readonly 全局 | 无 | readonly | **RLS** |
| **Secret Manager** | 无 | 无 | 无 | 集成 |
| **分支管理** | 无 | 无 | 无 | 无（Neon 有） |

**优势项：** 引擎覆盖最广、工具数最多、安全防护最全面、独有脱敏/建议/回放能力。

**劣势项：** 传输协议落后（缺 HTTP）、无企业级认证（OAuth/RBAC）、无 Secret Manager 集成。

## 6. v1.6 迭代建议
