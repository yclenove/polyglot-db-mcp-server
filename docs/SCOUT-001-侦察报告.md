# SCOUT-001 市场侦察报告

> 日期：2026-05-05 | 版本：v1.5.0 | 侦察员：AI Scout

---

## 1. 市场信号摘要

| 维度 | 信号强度 | 关键发现 |
|------|----------|----------|
| MCP 生态 | **高** | Streamable HTTP 传输取代旧 SSE；OAuth 2.1 认证成为标准；跨平台采用加速 |
| 数据库工具 | **中** | Chat2DB、AI2SQL、Supabase AI 等 AI 数据库工具涌现 |
| 竞品动态 | **高** | DBHub (bytebase) 是直接竞品，支持多引擎 |
| 用户痛点 | **高** | 安全审计、权限控制、数据脱敏是核心诉求 |
| 技术趋势 | **中** | 参数化查询、连接池优化、RASP 防护成为主流 |

---

## 2. 竞品动态

| 竞品 | 引擎支持 | 特点 | 威胁等级 |
|------|----------|------|----------|
| **DBHub** (bytebase) | PG/MySQL/SQLite/MSSQL | 官方推荐、活跃维护 | **高** |
| **Supabase AI** | PostgreSQL | 深度集成、云端优先 | 中 |
| **Chat2DB** | 多引擎 | 可视化 UI、AI 辅助 | 中 |
| **AI2SQL** | 通用 SQL | 自然语言转 SQL | 低 |

---

## 3. 技术趋势

| 趋势 | 成熟度 | 采纳建议 | 优先级 |
|------|--------|----------|--------|
| Streamable HTTP 传输 | 稳定 | 替换现有 SSE 实现 | **P1** |
| OAuth 2.1 认证 | 成熟 | 为企业用户提供认证层 | P2 |
| 连接池监控指标 | 成熟 | 已有 Prometheus 指标，保持 | P3 |
| RASP 运行时防护 | 新兴 | 关注但暂不采纳 | P4 |
| AI 辅助查询优化 | 成熟 | 已实现 query_suggest，可增强 | P3 |

## 4. 用户痛点

| 痛点 | 当前覆盖 | 改进空间 | 优先级 |

## 5. 机会清单 (v1.6 候选)
