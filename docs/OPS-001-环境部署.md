# OPS-001 环境部署指南

> 版本：v1.5.0 | 日期：2026-05-05

---

## 1. 环境变量清单

### 必填

| 变量 | 说明 |
|------|------|
| `DB_MCP_CONNECTIONS` | 连接 JSON 数组 |

### 可选（v1.4）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_MCP_DEFAULT_CONNECTION_ID` | 数组第一项 | 默认连接 ID |
| `DB_QUERY_TIMEOUT` | 30000 | 查询超时(ms) |
| `DB_MAX_ROWS` | 100 | 单次最大返回行数 |
| `DB_MAX_SQL_LENGTH` | 102400 | SQL 最大长度(bytes) |
| `DB_RETRY_COUNT` | 2 | 只读查询重试次数 |
| `DB_RETRY_DELAY_MS` | 200 | 重试基础延迟(ms) |
| `LOG_LEVEL` | info | 日志级别 |
| `LOG_FORMAT` | human | 日志格式 |

### v1.5 新增

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_MASKING_MODE` | off | 数据脱敏模式：strict/loose/off |
| `DB_MASKING_EXCLUDE_FIELDS` | 空 | 脱敏白名单字段（逗号分隔） |
| `DB_REPLAY_BUFFER_SIZE` | 50 | 查询回放缓冲区大小 |
| `DB_SUGGEST_TIMEOUT_MS` | 3000 | 查询建议分析超时(ms) |

---

## 2. Docker 部署步骤

```bash
# 1. 克隆仓库
git clone <repo-url> && cd polyglot-db-mcp-server

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填写 DB_MCP_CONNECTIONS 等实际值

# 3. 启动所有服务（含数据库 + MCP Server）
docker compose up -d

# 4. 查看服务状态
docker compose ps

# 5. 查看 MCP Server 日志
docker compose logs -f mcp-server
```

---

## 3. 健康检查

```bash
# 容器级健康检查（自动执行 scripts/healthcheck.mjs）
docker inspect --format='{{.State.Health.Status}}' polyglot-db-mcp-server-mcp-server-1

# MCP 工具级健康检查（通过 MCP Client 调用）
# tool: health_check — 测试所有连接状态和延迟

# 手动验证环境变量
docker compose exec mcp-server node scripts/healthcheck.mjs
```

---

## 4. 回滚方案

```bash
# 1. 停止当前版本
docker compose down

# 2. 切换到上一版本镜像
git checkout v1.4.0
docker compose build mcp-server

# 3. 回退 .env 中的 v1.5 变量（注释或删除）
# DB_MASKING_MODE=off
# DB_MASKING_EXCLUDE_FIELDS=
# DB_REPLAY_BUFFER_SIZE=50
# DB_SUGGEST_TIMEOUT_MS=3000

# 4. 重新启动
docker compose up -d
```

> v1.5 新增的 4 个环境变量均有默认值，回滚到 v1.4 时无需清理，未设置即使用 v1.4 行为。
